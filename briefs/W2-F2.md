Wave: 2 (continuation), second part of the W2-F series. Base: PR #7 head (W2-F1). End tag: `w2-f2` (created at merge). Branch: `claude/wave-2f2-group-transform` (stacked on PR #7).

## 1. Goal

1. The dashed multi-selection box from W2-F1 gets handles. Its corners resize every selected object together, its edges stretch them along one axis, and its rotate handle turns them all about the box center. Each gesture is one undo step (CV-041).
2. Reproduce and fix spec bug 5, "object scaling produces disproportionate or oversized results" (CV-007).

## 5. Contracts, schema and dependencies

- **`TRANSFORM_INTERACTION_CONTRACT.md` revision 6** (owner-authorized with W2-F; D-077). The multi-selection box is covered by a new section. The corner multiplier rule changes to the pointer's projection onto the corner diagonal, which is the scaling fix. `TRANSFORM_CONTRACT.md` gets a pointer note only.
- **Schema stays 5.** No dependency is added. Core gains `decomposeMatrix` (additive).

## 6. Design notes

- **Reproduction first.** A 16:9 image fitted to the canvas was dragged 40 CSS px diagonally at its bottom-right corner. The old rule picked the larger relative change: +10% from the height, against +5.6% from the width. So the image grew 128 units while the pointer moved 72, and the corner ran ahead of the pointer.
- **The fix** projects the pointer onto the diagonal (`m = d·v / v·v`), so the corner follows the pointer. The same rule is used for the multi-selection box.
- **Multi-selection:**
  - `render/selection.ts`: `multiSelectionFrame`, `multiSelectionGeometry` (the handles), `multiSelectionStretchable` and `hitMultiHandle`.
  - `ui/transform-interaction.ts`: the multi gesture, with the world delta `multiAffine`; every root gets `P⁻¹·A·P·L` through `decomposeMatrix`; the frame is previewed transformed.
