### Step 4: read-only test hook (DEV-005)

- `src/dev/test-hook.ts`, installed only when `import.meta.env.DEV` or `MODE === 'e2e'`. `window.__AIVE__` exposes `version`, `getProject()` (deep-frozen JSON clone), `getSession()` (composition ID, selected IDs, time, playing, canvas zoom, timeline px per second), `getHistory()` (`canUndo`, `canRedo`, last 30 step labels), `getConsoleErrors()`. It never exposes mutating engine functions.
- Use the hook to read state in tests. Do not click the Export button to read state: it moves keyboard focus away from the timeline and disables timeline shortcuts.
- Vitest `[DEV-005]`: returned objects are frozen and mutation attempts do not change the engine. `scripts/assert-no-test-hook.mjs` (provided) runs in `verify`.

### Step 5: debug report (DEV-007)

- `src/dev/debug-report.ts` plus a small "Copy debug report" button in the status bar and Ctrl+Shift+D. JSON schema id `aive-debug-report/1`: `createdAt`, `app` (version, git commit injected at build, else `unknown`), `env` (user agent, language, viewport, devicePixelRatio), `editor` (composition ID, selected IDs, time, playing, zooms), `recentCommands` (last 30), `recentErrors` (last 50: time, kind, message, first 5 stack lines), `project` (full JSON when at most 200 KB, else `{omitted:true, sizeBytes, sha256}`). No media bytes, no other localStorage keys. Clipboard failure falls back to a file download. The buffers are observability only, not a second editor store.
- Tests: Vitest structure test and an e2e test that clicks the button and parses the copied JSON `[DEV-007]`.
