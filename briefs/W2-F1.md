# Brief W2-F1: selection core, capability menus, multi-selection box, Ungroup and layer order

Wave: 2 (continuation), first part of the W2-F series (Canva parity). Base: PR #6 head `5944b11` (W5-C). End tag: `w2-f1` (created at merge). Branch: `claude/wave-2f-canvas-parity` (stacked on PR #6).
Authority: `AGENTS.md`, then this brief, then `docs/FEATURES.md`. Reference: `docs/specs/CANVA-PARITY-SPEC.md` (sections 3, 5, 6 and 8).

## 1. Goal

The owner compared the canvas with Canva and listed what is missing. This part builds the base that the rest of W2-F uses, and fixes three of the listed bugs:

1. **One selection system.** A single description of what is selected and what each item can do. The right-click menu, a new action cluster and (later) the toolbar and the timeline clip context all read it, so there are never two parallel menu or selection systems.
2. **Menus offer only what the whole selection supports.** Speed, Reverse, Freeze frame and Detach audio no longer appear when an image, shape or text is in the selection (spec bug 2).
3. **Multi-selection is visible.** One dashed box around the selection, each object's own outline, and a small action cluster with Group, Duplicate, Delete and More (spec section 5, steps 1, 2 and 4; bug 1).
4. **Ungroup** in the menu, the cluster and on Ctrl+Shift+G (bug 4), including groups that were moved, scaled or rotated.
5. **Layer order**: Bring to front, Bring forward, Send backward, Send to back in a Layer submenu, the palette, and Ctrl+] / Ctrl+[.
6. **The duplicate-import report** (bug 6): reproduce, and guard.

## 5. Contracts, schema and dependencies

- **Schema stays 5.** No dependency is added.
- **Interaction contract unchanged.** The dashed box is drawn only; its handles come with revision 6 in W2-F2.
- **Ungroup keeps the frozen core rule.** Core `UNGROUP` still refuses a transformed group. The UI first sets each child's transform to the group's transform composed with its own, and the group's transform to the identity, then ungroups — all in one transaction (owner decision, D-074).

## 6. Design notes

- `src/ui/selection-context.ts`: `describeSelection(source, ids)` returns the items with their capabilities (`edit`, `clip`, `time-effects`, `detach-audio`, `group`, `transform`) and `every`/`some` checks. `time-effects` is only for video and audio clips.
- `contextActions` (editing.ts) is rebuilt on it, so the canvas menu, the timeline menu, the palette and the shortcuts all follow the same rule.
- `src/ui/context-menu.ts`: a generic renderer for menu entries (item, checkbox, radio, submenu with Back, toggle). `src/ui/canvas-menu.ts` builds the canvas entries.
- `src/ui/selection-actions.ts`: the action cluster, positioned above the selection box's top-right corner, beside a narrow box, or below when there is no room. It hides while dragging, drawing or playing.
- `src/ui/ungroup.ts`: `bakeTransform` composes the matrices and decomposes the result into position, rotation and scale; it refuses anything that would need a skew. `ungroupBlocker` names the reason when Ungroup cannot run (animated group or child, group settings, locked track, clip presets, skew).
- `src/ui/arrange.ts`: layer order moves each selected root among its siblings, keeping blocks together; one undo step.
