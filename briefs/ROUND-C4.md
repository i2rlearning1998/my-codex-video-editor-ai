The owner makes it with Claude (Door 1: Circumference from scratch through the MCP), turns that Project into a Style, tests it, and publishes it. ## TEXTS (written by the architect; load word for word where a text is given; the owner can edit these in Admin afterwards)

### T1. Builder plain messages (English; write the Hindi yourself, short and plain, and list it in the report for the owner to read)

- publish-needs-tests: "A Style can be Published only after three passed tests on three different topics. This one has {n} passed on {m} different topics. Add the missing tests, or write a reason to publish anyway."
- publish-blocked-invalid: "This Style does not pass its checks, so it cannot be Tested or Published. Fix the problems listed below first."
- template-missing-slot: "The template uses {{{name}}} but the slot list has no slot with that name."
- template-unused-slot: "The slot \"{name}\" is in the list but the template never uses it."
- template-not-plan: "This is not a Video Plan the platform can read. Paste the plan the template was made from."
- delete-warning: "Deleting this Style hides it from everyone. Projects already made from it keep working. You can restore it from the Deleted list."
- from-project-no-plan: "This Video was made by hand, so there is no plan to turn into a Style. Open it in AI mode or make it through Claude first."
- plan-locked: "This Style is part of the {plan} plan."
- import-newer: "This file was made by a newer version of the platform. Nothing was changed."
- import-clash: "A Style with this id already exists. Import it as a copy, or as a new version of the existing one?"
- rollback-bad: "That version can no longer be read, so it cannot be restored. Nothing was changed."
- look-no-hindi: "This look has no Hindi name yet; people who read Hindi will see the English name."
