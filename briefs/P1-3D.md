# Brief P1-3D: 3D models (GLB) in the editor (Phase 1, slice 1)

Owner approval: 3D library import into the editor (chat, Oct 2026). Blender-like 3D mode is a later, larger job.

## In scope

- P13D-001, P13D-002 (docs/FEATURES.md, section P13D).

## Design (schema 9 unchanged)

- The vendored THREE bundle gains `GLTFLoader` (`src/freecode/build-vendor.mjs`; three 0.170.0 examples/jsm, MIT).
- `src/code-layer/glb-source.ts` turns a .glb (binary glTF 2, up to 700 KB) into a Tier C module with the bytes embedded, so the result is an ordinary code layer: same bake, cache, export, templates and controllers.
- AI › Import and a file dropped on the editor accept .glb.

## Non-goals / stop rules

- Models above 700 KB need a new asset type (bytes in the media store, a reference in the layer). That is a schema change and needs the owner's authorization (AGENTS.md section 10). Not started.
- No animation clips, cameras or lights from the file; no Blender-like 3D mode.
