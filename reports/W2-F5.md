# Report: Wave 2 part F5 (W2-F5): text styling from the toolbar (2026-09-26)

## 1. Summary

- **The text toolbar's Font, Weight, Align and Spacing controls now work.**
  - **Font:** seven system fonts (Arial, Verdana, Tahoma, Trebuchet MS, Georgia, Times New Roman, Courier New).
  - **Weight:** Regular, Semibold or Bold, plus an **Italic** button.
  - **Align:** left, center, right or justified.
  - **Spacing:** a second toolbar row with line height, letter spacing, paragraph spacing and **Case** (UPPERCASE, lowercase, Title Case).
- **Each change is one undo step.** Case only changes how the text looks: the typed text is kept.
- **The box grows to fit.** When a larger line height or paragraph spacing needs more room, the text box grows in the same step, so the selection outline still matches the text.
- **Still not possible:**
  - the real font picker with more fonts and uploads (Wave 3);
  - weights that depend on the font, and variable fonts (TXT-010 is Claimed);
  - vertical alignment, outline and shadow.

## 7. Not tested, known gaps, risks

- **The fonts are system fonts.** A font missing on a machine falls back to its generic family (sans-serif, serif or monospace). Export draws with the same fonts in the same browser, but another machine may show a different face.
- **Text can overflow sideways.** Letter spacing or a wider font can push unwrapped text past the box's right edge, where it is clipped, as a large font size already is (backlog).
- **Copy style does not carry the new text settings** (backlog).
- **Not tested:**
  - justify with a single very long word;
  - Hindi (Devanagari) text with letter spacing, which Canvas applies per character and which can loosen conjuncts;
  - right-to-left text;
  - exporting a styled text layer (it shares the drawing code with the preview, EXP-007, but no new export test was added).
