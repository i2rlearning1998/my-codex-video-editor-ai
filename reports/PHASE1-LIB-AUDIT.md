## P1-03 What is reused (no new item format)

- Item payloads are the existing `LibraryItem` records of `src/library/schema.ts`, validated with `libraryItemSchema` / `parseLibrary`. The editor rebuilds the same `LibraryManifest` from the catalog, so the panels, the insert code and the render path stay as they are.
- Themes and styles are the Creator Pack `theme` and `style` kinds (`src/creator-pack/schemas.ts`). Packs to publish go through `checkPack(input, options)` (`src/creator-pack/check.ts`) and the existing render checks.
- Sounds are WAV media files (the existing media import path), with a waveform thumbnail.
- The catalog wrapper (manifest, category index, entry metadata) is transport only: it carries these records, it does not define a new kind of item.
