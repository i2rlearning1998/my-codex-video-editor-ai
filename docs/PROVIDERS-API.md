# Providers API

All public exports are in `src/providers/index.ts`. No adapter performs a request on import. Speech kinds are declarations only; stock operations are not TTS/STT synthesis/transcription implementations.

## Contract and exports

- Types: `ProviderKind`, `StockKind`, `Provider`, `StockItem`, `StockLicense`, `StockFile`, `SearchOptions`, `SearchResult`, `LicenseMeta`, `ProviderDependencies`, `KeyStore`, `KeyStorage`, `KeyTestResult`, `FetchLike`, `Network`, `RequestPolicy`, `SearchCache`, `CacheBackend`, `CacheEntry`, `ImportOptions`, `StockImport`, `ProviderErrorCode`.
- `createProviderRegistry()` returns `register(provider)`, `list()`, `get(id)`, `listByKind(kind)`; singleton `registry` and those four functions are exported. Duplicate ids reject. Register the four factory results once during app startup; no hidden auto-registration.
- Adapter factories: `createPixabay(deps?)`, `createPexels(deps?)`, `createIconify(deps?)`, `createFreesound(deps?)`. Inject `{network, keys, cache}` for a future server transport or tests. Default instances share transport rate state/cache. Each implements `search(options)`, `getDownload(item, quality, signal?)`, and `probe(signal?)`.
- Search accepts kind/query, optional page (1-based)/perPage (20 default), orientation (landscape/portrait/square), minWidth/minDuration/maxDuration and signal. Sizes clamp to upstream bounds. Unsupported upstream filters apply to returned items without altering upstream pagination. `total` is upstream accessible total (Iconify: lower bound, not a global count); `nextPage` is number or null. Empty filtered pages can still have a next page.
- `getDownload` resolves one exact `files[].quality` without network; use its opaque quality string (Pexels video includes file id). `importStockItem(item, quality, options?)` fetches bytes, enforces a streaming 200 MiB default limit, and returns `{blob,mime,name,licenseMeta}`. Options: signal/maxBytes/network/now. Freesound files are labelled preview-hq/preview-lq, never represented as originals. Pixabay original images only appear when the API actually supplies their URL.
- `createKeyStore(storageGetter?)`, singleton `keyStore`, `getKey(providerId,field='apiKey')`, `setKey(providerId,field,value)`, `clearKey(providerId,field='apiKey')`, `hasKeys(provider)`, `maskKey(value)`, `testKey(provider,signal?)`. Freesound field is `token`. Multi-field requirements are supported. Local storage uses one JSON string per field under `aive.provider-key.<encoded provider>.<encoded field>`; failures fall back to the current session. Keys are not encrypted and are readable by same-origin script; never include them in project files or logs. Masking hides all short keys; long keys show only the last four characters.
- `testKey` performs exactly one minimal uncached request when credentials exist and local throttling permits. Returns `{status:'ok'}` or `{status:'invalid-key'|'rate-limited'|'network',code,retryAt?}`; missing keys make zero requests. No request body, URL or upstream exception is exposed.
- `createNetwork({fetch?,now?,timeoutMs?})` provides `json(url,policy?)` and `request(url,policy,consume)`. Default 15-second timeout covers body consumption. Abort, timeouts, 429 Retry-After (seconds/date), exponential fallback and provider budgets are fail-fast: return `retryAt` epoch milliseconds, do not sleep/retry. UI schedules only a user-requested retry after that time. Budgets are per session/key; upstream limits across tabs/devices remain authoritative. Pexels monthly headers can block calls until reset. Client monthly cap uses a conservative rolling 31 days.
- `ProviderError` codes: `KEY_MISSING`, `KEY_INVALID`, `RATE_LIMITED`, `NETWORK`, `CORS_BLOCKED`, `BAD_RESPONSE`, plus `ABORTED`, `SIZE_LIMIT`. Fixed plain messages cannot echo credentials. A browser TypeError cannot prove CORS versus DNS/offline; download TypeErrors are classified as CORS_BLOCKED with conditional wording. Search transport failures are NETWORK. Opaque responses are CORS_BLOCKED. Redirects are rejected to avoid forwarding key-bearing API requests.
- `retryAfter(value,now,fallback?)`, `searchCacheKey(provider,options)`, `createSearchCache({ttlMs?,now?,backend?})`, `indexedDbCache()`; cache methods `get(key)`/`set(key,value,ttlMs?)`. IndexedDB database `aive-provider-cache`, object store `search`; 10-minute default TTL, 24 hours for Pixabay. Cache keys omit credentials/signals. Memory is capped at 200 writes; IndexedDB entries expire logically (disk eviction is a future maintenance task). No live API calls in tests.
- Constants/functions: `PIXABAY_LICENSE`, `PEXELS_LICENSE`, `COMMERCIAL_ICON_LICENSES`, `STICKER_PREFIXES`, `soundLicense(url)`, `assertActive(signal?)`.

## Media library integration

`Asset.metadata` in `src/core/model.ts` is already `z.record(jsonSchema)`, so no schema bump or core edit is needed. Call `attachStockLicense(asset, result.licenseMeta)` in the `addAsset` callback of `src/media/import.ts`, before the existing `ADD_ASSET` library command. It returns a new asset with `metadata.stockLicense` and preserves the other metadata. Import result bytes become a File for the existing importer and remain in the media store. Pass the resulting asset through the existing command path so the licence record survives save/reload. Do not drop metadata when deduplicating or replacing media. This UI/import callback wiring is intentionally not changed here.

## UI contract

Stock tabs call `listByKind`, render provider keyFields (secret input only where specified), and gate search with `hasKeys`. Display provider.attribution prominently above results, per-item author/source links and a licence badge. `commercialUse:false` must not look commercially cleared; show actual licence link and restrictions (including share-alike). Reset page to 1 on query/filter/provider changes; cancel the previous request. Render each returned file quality, call `importStockItem` on explicit selection, then preserve metadata as above. CORS failure is recoverable: show the typed message; a future authenticated server proxy is the fix, not no-cors fetch or browser-security workarounds.

To add a provider: implement Provider, declare kinds/keyFields/attribution, validate response JSON, return normalized files/licences, add fixture tests, register it. Add separate speech capability methods/types later without changing registry/key/cache/transport infrastructure. No speech provider is advertised as usable now.

## Provider rules checked 2026-10-17

| Provider  | Rate / cache                                                     | Attribution and licence rule                                                                                                                                                                                                                                                                   |
| --------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pixabay   | 100 / 60 seconds / key; mandatory 24-hour cache                  | Show Pixabay source with search results. Content Licence permits commercial uses subject to restrictions; no standalone resale/mass download. Download selected media, do not permanently hotlink photos.                                                                                      |
| Pexels    | 200 / hour; 20,000 / month; read X-Ratelimit headers             | Prominent “Photos provided by Pexels” link and photographer credit in results. Pexels content licence does not itself require attribution; API display requirements still apply.                                                                                                               |
| Iconify   | No fixed public quota established in cited search docs; obey 429 | Preserve icon-set licences/author. Default SPDX allow-list: MIT, ISC, Apache-2.0, BSD-2-Clause, BSD-3-Clause, CC0-1.0, CC-BY-4.0, CC-BY-SA-4.0, OFL-1.1. All except CC0 conservatively require notices/attribution. Stickers: OpenMoji, Noto, Noto-v1. Unknown/NC licences excluded.           |
| Freesound | 60 / minute; 2,000 / day; originals have stricter OAuth limits   | Per-sound CC0/CC-BY/CC-BY-SA/NC classification; unknown is not commercially cleared. MP3 previews use token authentication; original downloads need OAuth. Commercial **API** terms are negotiated separately with UPF; a commercial sound licence alone does not grant commercial API access. |
